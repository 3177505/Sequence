ML trénink

Tlačítka v prohlížeči (krok za krokem): ML průvodce — jen s npm run dev.

Co to vlastně dělá (velmi stručně):

Představ si obří hotový generátor obrázků z textu — to je Stable Diffusion 1.5. Už umí kreslit spoustu věcí, protože se kdysi učil na miliardách obrázků z internetu. Ty ho neprogramuješ od nuly.

LoRA je malý doplněk (jako tenká knížka navíc k velké encyklopedii): na tvém počítači se naučí víc „tvé“ estetiky z fotek v public/4_Research (přes plochou složku ml/data/instance_flat). Výstup ukládáme do ml/outputs/lora-run.

Technicky: knihovna Hugging Face Diffusers + oficiální skript train_dreambooth_lora, spouštěný přes accelerate (nastaví, jestli jede CPU, GPU, …).

Dlouhé tréninkové běhy na CPU (běžné na Macu bez výkonné karty) trvají velmi dlouho. Na Windows s NVIDIA GPU je to v praxi o řád rychlejší. Soubor 251205_cc8_gpu_accelator.py v public/ je něco jiného (hrání s piny v klasifikační síti), ne tento trénink.

Postup: Mac a Windows vedle sebe

Jedno společné: složka projektu musí být stejná, virtální prostředí v ml/.venv a trénink přes ml/launch_train.py (nebo launch_train.sh na Macu/Linuxu).

Mac (Terminal)

Jednorázově: vytvoř ml/.venv, nainstaluj ml/requirements.txt, spusť accelerate config (odpovídej podle karty — na CPU bývá „no“ u mixed precision).

cd ml
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -c "import numpy; assert numpy.__version__ < '2'" || pip install "numpy>=1.26,<2"
accelerate config
chmod +x launch_train.sh
MAX_TRAIN_STEPS=200 ./launch_train.sh

MAX_TRAIN_STEPS=200 (nebo 400) zkus na CPU dřív než 800. Plný běh bývá hodinový až denní. Nebo: python launch_train.py (stejná logika jako skript sh).

Windows (Terminal)

Stejná struktura, jiné cesty a aktivace venv. Doporučen je Python 3.10+ a PyTorch s CUDA, pokud máš NVIDIA (rychlé učení).

cd ml
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install "numpy>=1.26,<2" diffusers==0.32.2 "huggingface-hub>=0.34.0,<1.0"
accelerate config
set MAX_TRAIN_STEPS=200
set RESUME=
python launch_train.py

Příkazová řádka cmd. V PowerShell: $env:MAX_TRAIN_STEPS=200 místo set.

Pro pokračování: set RESUME=1 a znovu python launch_train.py, pokud existuje checkpoint v outputs/lora-run.

Prohlížeč s tlačítky (Windows i Mac)

Ve složce ml-gui/ je malá stránka (Gradio): tlačítko pro start tréninku, log, druhé tlačítko pro generování. Potřebuje lehký install jen pro UI — viz ml-gui/README.md. Stejná ml/.venv s PyTorchem musí být hotová. 

cd ml-gui
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py

Na Windows: .venv\Scripts\python app.py a otevře se prohlížeč na 127.0.0.1:7860.
