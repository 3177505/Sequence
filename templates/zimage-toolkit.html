Chyba: No matching distribution found for torchcodec==0.9.1 (u tebe s pip už skoro hotovo)

    
Na macOS Intel (x86_64) často neexistuje normální wheel pro přesné torchcodec z requirements Ostris — na PyPI u té kombinace zůstává jen prázdný 0.0.0.dev0. Apple Silicon (M čipy) a Linux (RunPod, cloud GPU) jsou cesty, které u Ostris reálně fungují; projekt cílí hlavně na NVIDIA + Linux/Windows.

    
Co můžeš zkusit na Intel Macu na vlastní riziko (zálohuj repozitář, čistý stav: git checkout -- requirements_base.txt když potřebuješ vrátit): v ~/ai-work/ai-toolkit otevři requirements_base.txt, dočasně smaž nebo vyškrtni celý řádek s torchcodec, ulož, pak z aktivovaného venv znovu python -m pip install -r requirements.txt. Import v části nástroje pro video pak může chybět — obrázkový / Z-Image LoRA bývá u některých větví v pohodě, u jiných ne. Spolehlivá varianta je Linux + GPU v cloudu dle README u Ostris.
