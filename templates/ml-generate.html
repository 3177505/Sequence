ML generování

Průvodce s tlačítky: ML průvodce.

Co se děje, když to spustíš:

Znovu stejná báze: model Stable Diffusion 1.5 — vybere se podle anglického textu (promptu) a vykreslí jeden nebo víc PNG.

Volitelně načteme LoRA ze složky ml/outputs/lora-run, pokud jsi trénink už dohnal a uvnitř jsou soubory. Bez toho to pořád funguje jako „obecný“ SD1.5 — jen méně „tvé“.

Skript je ml/generate.py (knihovna Diffusers). Výstupy: ml/outputs/gen/ (např. out_00.png, out_01.png pro dvě plochy).

Postup: Mac a Windows

Mac (Terminal)

Stejné venv jako u tréninku: cd ml → source .venv/bin/activate.

S LoRA (až bude v outputs/lora-run něco uloženo):

cd ml
source .venv/bin/activate
python generate.py \
  --lora outputs/lora-run \
  --prompt "a sksseq photograph, research images, detailed" \
  --out-dir outputs/gen \
  --count 2

Bez LoRA (hned, bez tréninku):

python generate.py \
  --prompt "a sksseq photograph, abstract, detailed" \
  --out-dir outputs/gen \
  --count 2

Windows (Terminal)

Stejné příkazy v ml, aktivace: .venv\Scripts\activate.

S LoRA:

cd ml
.venv\Scripts\activate
python generate.py --lora outputs/lora-run --prompt "a sksseq photograph, research mood" --out-dir outputs\gen --count 2

Bez LoRA:

python generate.py --prompt "a sksseq photograph" --out-dir outputs\gen --count 2

Prohlížeč s tlačítky

Aplikace v ml-gui/ (python app.py) má záložku pro generování: zadáš prompt, volitelně LoRA, výstup se zobrazí v okně. Vyžaduje vytvořené ml/.venv a podle ml-gui/README.md venv pro Gradio, nebo nainstaluj gradio do ml/.venv.

Velký jazykový model (LLM) později

Běžné je nechat LLM jen napsat nebo vylepšit prompt a obraz stále kreslí SD+LoRA. Dvě fáze, dva programy; není to jedna „hádanka v jednom souboru“.
